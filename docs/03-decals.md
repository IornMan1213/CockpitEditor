# 3. Decals (painted markings)

Decals are flat markings such as **STEP HERE**, **NO STEP**, hazard stripes, placards or your own pictures.

## Add one

1. Open the **Add** tab.
2. Click a template: STEP HERE, NO STEP, Hazard stripes, EJECTION SEAT, Red stencil, White label, Placard,
   REMOVE BEFORE FLIGHT. (Or **Decal from a picture** for your own PNG; see below.)
3. Click the spot in the cockpit. It lies flat on the surface you click.

It is now selected and listed in **My items**.

## Change how it looks (right panel)

| Setting | What it does |
|---|---|
| **Name** | only for you, in the list |
| **Text** | the words. Press Enter for a second line. The text always fills the decal. |
| **Font** | Arial Black, Impact, Stencil, Bahnschrift, Arial, Consolas, Segoe UI |
| **Text colour**, **bold** | |
| **Background** | tick for a coloured plate behind the text; untick for letters only (only the letters appear in the game) |
| **Border** | an outline in its own colour |
| **Hazard stripes** | a black and yellow striped edge |
| **Corner round** | rounded plate corners |
| **Picture** | add or replace a picture inside the decal |

## Size and position

- **Width** / **Height** in centimetres. With **Keep shape** ticked they change together.
- **Fit height to the text** trims the height so the text fits snugly.
- **Rotation**, the nudge arrows, **Move**, **Duplicate** (Ctrl+D) and **Delete** (Del) work as for instruments.

## Your own picture

1. Make the picture in any paint program and save it as **PNG**. Transparent areas stay see-through: only the painted pixels
   appear in the game. Up to 1024 pixels is plenty (bigger ones are shrunk).
2. **Add** tab > **Decal from a picture (PNG)…**, choose the file, click the spot.
3. Set its width; the height follows the picture's shape.

You can also add text on top of a picture, or swap the picture later with **Picture > Replace**.

## How it looks in the game

The game's cockpit material cannot be see-through, so the editor cuts each decal to its painted pixels when you save: letters
without a background come out as real letter shapes. Very fine details (hair-thin lines) may come out a little blocky; make
them a bit bolder.
