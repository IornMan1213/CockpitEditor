Cockpit setups (.cpit)

  

    
A setup is this whole cockpit in one file: moved instruments, decals, screens and MFD pages. Put .cpit files in the Cockpits folder next to the jet's plugin and pick one in game: Configuration Manager (F1) > Cockpit > Cockpit layout, or set a key to cycle them. A file that cannot be used falls back to the default cockpit.

Keys

      
Click a corner to select it, drag to move it. Arrows nudge 0.5 mm (Shift 5 mm, Ctrl 0.1 mm). Double-click an edge to add a corner there, Del removes the selected one, A adds one after it. Wheel zooms, right-drag pans. Dents are fine; an outline that crosses itself is shown red and cannot be used.

    

  






  
How to use the Cockpit Editor

  
    
    
  1. Pick the jet at the top left. Look around with the mouse; the buttons over the view jump to the panel, consoles and so on.
    2. 
    
  2. Rearrange (Layout tab): click a gauge, display, switch panel or knob. In the right panel: Move then click its new spot, nudge it with the arrows, turn it, make it bigger or smaller, or hide it. Reset puts it back.
    3. 
    
  3. Add (Add tab): a decal (STEP HERE, NO STEP... or your own picture) or a screen. Click it, then click where it goes; it sits flat on the surface you click.
    4. 
    
  4. Screens: pick what it shows and its shape. In the right panel set its size and edit its outline: drag the corner dots, double-click an edge to add a corner, right-click a dot to remove it.
    5. 
    
  5. Save (Ctrl+S). Build & Install builds the mod with your changes and copies it into the game (a few minutes; close Unity, and the game if you want it installed straight away).
    6. 
  

  
Keys (with something selected)

  
    
    
  • Arrows nudge 1 mm (Shift 1 cm) · Q/E turn 5° (Shift 1°) · +/- bigger / smaller
    • 
    
  • M move (click a new spot) · H hide / show (instruments) · Del delete (your items) · Ctrl+D duplicate
    • 
    
  • Ctrl+Z undo · Ctrl+S save · Esc cancel / deselect · F look at the selected one
    • 
  

  
Good to know

  
    
    
  • Everything is saved in the mod's cockpit\ folder (layout.json, custom.json, decal pictures), so it goes into every build from then on.
    • 
    
  • Moved instruments keep working (needles, lights, screens move with them). Something you hide disappears; the panel behind it is plain.
    • 
    
  • Screens show the same pages as the built-in ones and lay them out to fit; their outline is kept convex (no dents) so the pages fit. Very small screens get cramped.
    • 
    
  • A decal does not follow an instrument you move later: move the decal too.
    • 
    
  • New kinds of instruments or switches, and changes to the panel's shape itself, still need Claude. After Claude changes the cockpit, press Reload cockpit from mod in the Log.
