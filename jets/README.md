# Cockpit data

One folder per jet (`smt`, `mig29`) with the cockpit the editor shows: `cockpit_mesh.json`, `cockpit_atlas.png` and
`cockpit_atlas.json`, made by the mod's `blender/cockpit_build.py` (**Reload cockpit from mod** in developer mode writes them
here when `work` points at this folder). They are part of the mods' cockpits and share the mods' licence and credits.
